# 🧩 Caça-Palavras

Um jogo de caça-palavras clássico, leve e direto no navegador. 

O projeto foi desenvolvido com foco na simplicidade e facilidade de uso, oferecendo um passatempo direto ao ponto, livre de anúncios, menus confusos ou poluição visual.

## ✨ Características
- **Interface limpa:** Sem propagandas, cronômetros ou distrações na tela.
- **Leitura fácil:** Tipografia grande e de alto contraste para melhor visualização do tabuleiro.
- **Jogabilidade simples:** Controles diretos via clique ou toque na tela, sem configurações complexas.
- **Leve:** Roda diretamente no navegador em computadores, celulares ou tablets.
